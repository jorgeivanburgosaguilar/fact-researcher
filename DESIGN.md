# Design

## Dirección

Fact Researcher es un tomador de notas para verificación: una lista de registros clara y desktop-first, sin dashboard. El fact original permanece visible y ocupa la columna izquierda. La columna derecha concentra categoría, estado y notas para que la decisión quede junto al registro sin ocultar su fuente.

## Layout

La pantalla tiene un encabezado mínimo con nombre de archivo, selector de tema y exportación. Debajo se muestra una lista vertical de filas de dos columnas. Los bordes son discretos; el estado siempre aparece en texto y el color solo refuerza su significado. No hay filtros, progreso, contadores, evidencia separada, corrección propuesta, expansión ni variante móvil.

## Visual

Usar superficies neutras, reglas finas, tipografía de sistema y azul reservado para la acción principal. El tema oscuro se activa mediante `html.dark` y conserva contraste y foco visible. La interfaz no usa fuentes, imágenes ni recursos remotos.
